# 총원가 관리연결결산 프로세스 혁신(PI) 설계서
본 문서는 수기 기반 관리연결결산을 원가추적번호 기반 자동 물동 추적 체계로 전환하기 위한 설계 내용을 정의한다.
## 1. 현황 및 문제점
현재 전 법인 관리연결결산은 각 법인 담당자가 엑셀로 물동 내역을 취합한 뒤 본사가 수기로 대조하는 방식으로 수행된다.
법인별 원가 집계 기준이 상이하여 결산 마감까지 평균 5영업일이 소요되고 재작업이 빈번하다.
- 법인별 상이한 원가 코드 체계로 매핑 오류 발생
- 수작업 취합으로 마감 지연(평균 5일)
- 감사 대응 시 추적 근거 자료 확보 어려움
## 2. 원가추적번호(Cost Trace No.) 체계
전 법인 공통의 원가추적번호를 발번하여 원자재 이동부터 완제품 판매까지 전 구간의 물동을 하나의 키로 연결한다.
원가추적번호는 발생법인, 품목군, 순번으로 구성되어 법인 간 이관 시에도 동일하게 유지된다.
- 구성: 발생법인코드(3) + 품목군코드(4) + 순번(6)
- 전 법인 ERP 전표 생성 시 필수 입력 항목으로 지정
- 기존 원가센터 코드와의 매핑 테이블 병행 운영
### 2.1 전 법인 물동 추적 흐름
원자재가 A법인에서 B법인으로 이관될 때 원가추적번호가 함께 승계되어 이관 손익을 자동 산출한다.
물동 추적 대시보드는 추적번호별 현재 위치, 누적원가, 이관 이력을 실시간으로 제공한다.
- 이관 시 원가추적번호 자동 승계
- 실시간 물동 대시보드 제공
- 이관손익 자동 산출로 수기 대사 제거
## 3. 간접비 배부 설계
간접비는 활동기준원가(ABC) 방식을 준용하여 부문별 실제 활동량 기준으로 배부한다.
공통 지원부서 비용은 매출액과 인원수를 혼합한 배부동인을 적용한다.
- 생산부문: 작업시간 기준 배부
- 지원부문: 매출액 70% + 인원수 30% 혼합배부
- IT 인프라 비용: 서버 사용량 기준 배부
### 3.1 법인간 비용배분 기준
법인 간 공유 비용(공동 R&D, 공통 IT 시스템 등)은 사전 계약된 배분비율표에 따라 매월 자동 배분한다.
배분비율은 연 1회 실제 사용량을 재측정하여 갱신한다.
- 공동 R&D 비용: 법인별 매출 비중으로 배분
- 공통 IT 비용: 사용자수 비중으로 배분
- 연 1회 배분비율 재산정
## 4. 시스템 반영 방안
ERP 전표 입력 화면에 원가추적번호 필드를 추가하고 필수값 검증 로직을 반영한다.
관리연결결산 리포트는 원가추적번호 기준으로 자동 집계되도록 재설계한다.
- ERP 전표 화면 필드 추가
- 결산 리포트 자동 집계 로직 개발
- 기존 수기 취합 시트 단계적 폐지
## 5. 기대 효과 및 리스크
자동화를 통해 결산 마감 기간을 5일에서 2일로 단축하고 감사 대응 자료를 실시간 확보할 수 있다.
다만 전 법인 동시 전환 시 초기 데이터 정합성 오류 리스크가 존재하여 파일럿 적용이 필요하다.
- 기대효과: 마감기간 60% 단축
- 기대효과: 감사 대응 시간 단축
- 리스크: 초기 데이터 정합성 오류 가능성
