## 요건

Tesla와 Zara의 수직계열화 수준, 핵심 활동의 내부화 범위, 외부 공급업체 의존도를 비교한다. Tesla의 생산·배터리·소프트웨어 중심 통합 방식과 Zara의 빠른 생산·유통 통제 및 협력 네트워크 방식을 대조한다.

두 기업의 수요예측 방식 차이를 분석하고 예측 정확도, 시장 반응 속도, 재고 운영과의 연계성을 비교한다. 공급망 구조와 수요예측 방식이 리드타임, 재고, 제품 출시 및 대응 속도에 미치는 영향을 분석 지표로 반영한다.

각 비교 지표에는 공개자료의 기준 시점과 출처를 명시한다. 비공개 운영 데이터 및 알고리즘으로 인해 정성 분석에 의존할 수 있는 한계를 표기하고, 산업·제품 특성 차이에 따른 단순 비교 및 일반화의 한계와 cross-module 영향을 관련 산출물에 반영한다.

## 결정

Tesla·Zara 케이스 스터디 문서와 케이스 스터디 분석 프레임에 공급망 수직계열화, 내부화, 외부 공급업체 의존도, 수요예측, 재고, 리드타임 및 시장 대응 속도 비교를 반영한다.

산출물_설계서.docx에는 분석 범위와 cross-module 영향, 지표·출처 기준, 비공개 데이터에 따른 검증 한계 및 과도한 인과 해석 방지 기준을 반영한다. 요구사항_추적표.xlsx에는 변경 주장·요구사항·근거자료·검증 상태 간 추적 항목을 반영한다. 보고_장표.pptx에는 수직계열화와 성과 간 단정적 인과를 배제하고 산업 특성·자료 한계·정성 분석임을 명시한 요약 메시지를 반영한다.

산출물_설계서.docx, 요구사항_추적표.xlsx, 보고_장표.pptx는 deliverable_patch를 통한 GitHub Actions 문서엔진으로 실제 갱신 완료한 것으로 기록한다. LLM Wiki와 GitHub 반영도 완료한 것으로 기록한다.

## 영향 산출물

- Tesla·Zara 케이스 스터디 문서 — 공급망 및 수요예측 분석 수정
- 케이스 스터디 분석 프레임 — 비교분석 구조 및 일반화 한계 수정
- 산출물_설계서.docx — 분석 범위 및 cross-module 영향 수정
- 요구사항_추적표.xlsx — 공급망·수요예측 요구사항 추적 항목 수정
- 보고_장표.pptx — 비교분석 요약 메시지 수정
- LLM Wiki 및 GitHub — 요구사항·결정·키워드 인덱스 반영

## 실행 결과

- 케이스 스터디 문서에 수직계열화·내부화·외부 공급업체 의존도, 생산·유통 통제 방식, 수요예측·재고·리드타임·시장 대응 속도 비교를 반영했다.
- 분석 프레임에 산업·제품 특성 차이를 고려한 비교 지표, 일반화 한계 및 cross-module 영향을 반영했다.
- 설계서·요구사항 추적표·보고 장표를 deliverable_patch 기반 GitHub Actions 문서엔진으로 갱신 완료했다.
- 공개자료의 기준 시점·출처와 정성 분석 한계를 명시했다.
- 팀 채널 공지문 초안에 반영 완료 사실과 직접 비교의 한계를 포함했다.

## 리스크

- 공개자료의 범위와 기준 시점이 달라 두 기업의 수직계열화 및 수요예측 수준을 동일 기준으로 비교하기 어려울 수 있다.
- 기업별 세부 수요예측 알고리즘과 운영 데이터가 비공개여서 정성적 분석에 의존할 수 있다.
- Tesla와 Zara의 산업·제품 특성 차이로 비교 결과가 과도하게 일반화될 수 있다.
- 비교 지표의 정의나 출처가 불명확하면 예측 정확도, 재고, 리드타임 및 대응 속도 해석에 편향이 발생할 수 있다.
- DA는 통과 기준 충족을 확인했으나 비교 지표·근거·범위·검증 매핑 및 컴플라이언스 검토 보완을 권고했다(score 5).
