# SAP FI 연결결산 내부거래대사 효율화 설계서
본 문서는 법인 간 내부거래대사의 키 매핑 구조를 표준화하고 결산리포트 대사결과 확인 작업을 효율화하기 위한 설계 내용을 정의한다.
## 1. 현황 및 문제점
현재 내부거래대사는 법인별로 상이한 거래키 체계를 사용하여 담당자가 수작업으로 매칭 작업을 수행하고 있다.
결산 시즌마다 불일치 건수가 평균 200건 이상 발생하며 원인 추적에 상당한 시간이 소요된다.
- 법인별 거래키 체계 불일치
- 결산 시 불일치 건수 평균 200건 이상
- 원인 추적을 위한 수작업 조회 반복
## 2. 내부거래대사 키 매핑 구조
표준 대사키는 거래상대법인코드, 전표유형, 참조문서번호의 조합으로 정의하여 양측 법인에서 동일하게 생성되도록 한다.
기존 법인별 로컬 키는 표준 대사키로 변환하는 매핑 테이블을 통해 하위호환을 유지한다.
- 표준 대사키 = 상대법인코드+전표유형+참조문서번호
- 로컬 키 → 표준 키 매핑 테이블 운영
- 신규 전표는 표준키 직접 생성 원칙
### 2.1 매핑 테이블 설계
매핑 테이블은 SAP 커스텀 테이블로 구성하며 법인쌍, 매핑규칙, 검증상태 컬럼을 포함한다.
매핑 규칙 변경 시 이력 관리를 위해 변경일자와 변경자를 함께 기록한다.
- 법인쌍별 매핑 규칙 1:1 관리
- 규칙 변경 이력 자동 기록
- 검증 실패 건은 예외 큐로 분리
## 3. 결산리포트 대사결과 확인 프로세스
결산리포트는 표준 대사키 기준으로 양측 법인 전표를 자동 매칭하여 대사결과를 산출한다.
불일치 건은 사유코드와 함께 자동으로 담당자에게 배정되어 처리 현황을 추적할 수 있다.
- 표준키 기준 자동 매칭
- 불일치 건 사유코드 자동 태깅
- 담당자 자동 배정 및 SLA 추적
### 3.1 자동화 방안
매칭 배치는 결산 마감 전 매일 1회 실행하여 불일치를 조기에 발견하도록 한다.
반복적으로 발생하는 불일치 패턴은 규칙 엔진에 학습시켜 자동 정정을 시도한다.
- 일 1회 사전 매칭 배치 실행
- 반복 불일치 패턴 자동 정정 규칙화
- 정정 불가 건만 담당자 검토
## 4. 효과 측정 지표
효과 측정은 불일치 건수, 매칭 소요시간, 결산 마감 준수율을 핵심 지표로 관리한다.
파일럿 법인 적용 결과 불일치 건수가 40% 감소한 것으로 잠정 확인되었다.
- 불일치 건수 40% 감소(파일럿 기준)
- 매칭 소요시간 단축
- 결산 마감 준수율 목표 98%
## 5. 리스크 관리
표준키 전환 초기에는 기존 로컬키 기반 리포트와 병행 운영하여 데이터 정합성을 검증한다.
법인별 시스템 반영 일정 차이로 인한 과도기 불일치 가능성에 대비한 예외 처리 절차를 마련한다.
- 병행 운영 기간 최소 1개 결산 주기
- 과도기 예외 처리 절차 사전 정의
