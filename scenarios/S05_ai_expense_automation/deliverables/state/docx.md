# AI 기반 여비교통비 경비 자동화 설계서
본 문서는 여비교통비 규정을 multi-hop으로 판독하고 증빙 서류를 OCR로 자동 처리하는 경비 자동화 체계를 정의한다.
## 1. 현황 및 문제점
현재 여비교통비 정산은 직원이 규정집을 직접 확인하여 한도를 파악하고 증빙을 수기로 첨부하는 방식이다.
직급, 출장유형, 교통수단에 따라 규정이 세분화되어 있어 정산 담당자의 판단 오류가 빈번하다.
- 규정 조항이 다단계로 얽혀있어 해석 오류 발생
- 증빙 첨부 및 확인이 전량 수작업
- 정산 처리 리드타임 평균 3영업일
## 2. 여비교통비 규정 구조
규정은 직급별 기준, 출장유형별 기준, 교통수단별 한도가 상호 참조되는 다층 구조로 되어 있다.
예를 들어 해외출장의 항공권 등급은 직급과 비행시간에 따라 달라지는 조건부 규칙을 갖는다.
- 직급별 기준(사원~임원 5단계)
- 출장유형별 기준(국내/해외/단기파견)
- 교통수단별 한도(항공/철도/자차)
### 2.1 Multi-hop 규정판독 로직
AI 판독 엔진은 직급 조건 확인 → 출장유형 확인 → 교통수단 한도 확인의 순서로 여러 규정 조항을 순차 조회한다.
각 hop에서 조회한 근거 조항을 함께 기록하여 정산 담당자가 결과를 검증할 수 있도록 한다.
- 1hop: 직급 조건 조회
- 2hop: 출장유형 조건 조회
- 3hop: 교통수단 한도 조회
- 각 hop 근거조항 로그 기록
## 3. 증빙 OCR 처리 흐름
영수증, 항공권, 숙박 바우처 등 증빙 이미지를 업로드하면 OCR 엔진이 항목별 금액과 일자를 자동 추출한다.
추출된 정보는 여비교통비 규정 판독 결과와 대사하여 한도 초과 여부를 자동 판정한다.
- 영수증/항공권/바우처 이미지 자동 인식
- 추출 항목: 금액, 일자, 사용처, 항목유형
- 한도 초과 시 자동 반려 및 사유 안내
### 3.1 예외처리 및 에스컬레이션
OCR 인식률이 임계치 이하인 증빙은 자동으로 수기 검토 큐에 배정된다.
규정 판독 결과가 상충하는 경우 정산 담당자 승인 후 인사팀 에스컬레이션 절차를 거친다.
- 인식률 90% 미만 시 수기검토 큐 배정
- 규정 상충 시 인사팀 에스컬레이션
- 반려 사유는 신청자에게 즉시 통지
## 4. 시스템 아키텍처
시스템은 OCR 모듈, 규정판독 LLM 모듈, 정산 시스템 연동 모듈로 구성된다.
규정 원문은 벡터 DB에 색인하여 LLM이 근거 조항을 검색 후 인용하도록 한다.
- OCR 모듈: 이미지→텍스트 추출
- 규정판독 LLM 모듈: 벡터DB 검색+추론
- 정산시스템 연동 모듈: 결과 반영
## 5. 기대효과 및 리스크
자동화를 통해 정산 리드타임을 3일에서 반나절로 단축하고 규정 오적용 사례를 최소화할 수 있다.
다만 OCR 오인식이나 신규 규정 미반영으로 인한 오판정 리스크에 대비한 상시 모니터링이 필요하다.
- 기대효과: 정산 리드타임 대폭 단축
- 기대효과: 규정 오적용 최소화
- 리스크: OCR 오인식/신규규정 미반영
