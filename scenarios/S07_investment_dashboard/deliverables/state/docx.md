# 투자 의사결정 대시보드 기획서
본 문서는 거시경제 패널과 종목 펀더멘털 패널로 구성된 투자 의사결정 지원 대시보드의 기획 내용을 정의한다.
## 1. 배경 및 목적
투자 담당자들이 거시지표와 종목 재무데이터를 각기 다른 화면에서 확인하여 의사결정 속도가 저하되고 있다.
본 대시보드는 거시경제 패널과 종목 펀더멘털 패널을 하나의 화면에서 교차 분석할 수 있도록 통합한다.
- 거시/종목 데이터 분산으로 의사결정 지연
- 교차분석 기능 부재
- 실시간성 부족
## 2. 거시경제 패널 구성
거시경제 현황 패널은 개별 종목 펀더멘털 분석 패널과 독립된 영역으로 정의하며, 금리·물가·환율·주요 지수 등 시장 전반 지표를 배치한다. 각 지표에는 기준 시각, 최종 갱신 시각, 데이터 출처, 지연 여부를 표시하고 지표 특성에 따라 실시간·일중·일간·주간·월간·발표 시점 갱신 유형을 적용할 수 있도록 한다.
거시경제 현황 패널은 개별 종목 펀더멘털 분석 패널과 독립된 영역으로 구성한다. 금리, 물가, 환율, 주요 지수 등 시장 전반을 설명하는 지표를 배치하고, 각 지표에 기준 시각, 최종 갱신 시각, 데이터 출처 및 지연 여부를 표시한다. 지표별 데이터 특성에 따라 실시간·일중·일간·주간·월간 또는 발표 시점 갱신 유형을 정책 항목으로 관리한다. 패널별 데이터 로딩 실패와 지연 데이터, 서로 다른 기준일 데이터가 혼재하는 경우 상태와 기준일을 구분하여 표시한다.
거시경제 패널은 금리, 환율, 물가, 유동성 지표를 카테고리별로 배치하여 매크로 사이클을 한눈에 파악할 수 있게 한다.
각 지표는 전월/전년 대비 변화율과 함께 표시되어 추세 판단을 돕는다.
- 금리: 기준금리, 국채금리 스프레드
- 환율: 원/달러, 원/엔
- 물가: CPI, PPI
- 유동성: M2 증가율
### 2.1 지표선정기준
지표 선정은 데이터 신뢰성(공신력 있는 기관 발표), 갱신주기, 시장 영향력을 기준으로 평가한다.
신규 지표 추가 요청은 분기별 검토위원회를 통해 승인한다.
- 공신력 있는 기관 발표 자료 우선
- 갱신주기 월 1회 이상
- 분기별 지표 검토위원회 운영
## 3. 종목 펀더멘털 패널 구성
개별 종목 펀더멘털 분석 패널은 거시경제 패널과 독립된 영역으로 정의하며, 매출·이익·밸류에이션·재무건전성·실적·컨센서스 지표를 배치한다. 각 지표에는 기준 시각, 최종 갱신 시각, 데이터 출처, 지연 여부를 표시하고 지표별 갱신 유형을 정의할 수 있도록 한다.
개별 종목 펀더멘털 분석 패널은 거시경제 현황 패널과 독립된 영역으로 구성한다. 매출·이익, 밸류에이션, 재무건전성, 실적 및 컨센서스 관련 지표를 배치하고, 각 지표에 기준 시각, 최종 갱신 시각, 데이터 출처 및 지연 여부를 표시한다. 지표별 데이터 특성에 따라 실시간·일중·일간·주간·월간 또는 발표 시점 갱신 유형을 정책 항목으로 관리한다. 공시·컨센서스 반영 지연과 서로 다른 기준일 데이터가 혼재하는 경우 해당 상태를 명확히 표시하며, 패널 단위 로딩 실패 시 오류 상태와 대체 표시 기준을 제공한다.
종목 패널은 밸류에이션 지표, 수익성 지표, 성장성 지표, 재무안정성 지표의 4개 그룹으로 구성한다.
업종 평균 대비 상대 위치를 함께 표시하여 종목 스크리닝에 활용할 수 있도록 한다.
- 밸류에이션: PER, PBR, EV/EBITDA
- 수익성: ROE, 영업이익률
- 성장성: 매출성장률, EPS성장률
- 재무안정성: 부채비율, 유동비율
### 3.1 재무지표 정의
재무지표는 최근 4개 분기 합산(TTM) 기준을 원칙으로 하며 일회성 손익은 조정하여 산출한다.
업종 분류는 GICS 기준을 채택하여 업종 평균 산출의 일관성을 확보한다.
- TTM 기준 산출 원칙
- 일회성 손익 조정 반영
- GICS 업종분류 채택
## 4. 화면 구성 및 UX
거시경제 현황 패널과 개별 종목 펀더멘털 분석 패널은 독립 영역으로 구성하며, 각 지표에 기준 시각·최종 갱신 시각·데이터 출처·지연 여부를 표시한다. 지표별 갱신 유형은 실시간·일중·일간·주간·월간·발표 시점으로 관리하고, 패널별 로딩 실패·지연 데이터·서로 다른 기준일 데이터 혼재 시 경고 상태를 표시한다.
메인 화면은 좌측 거시경제 패널, 우측 종목 펀더멘털 패널로 분할하여 동시 비교가 가능하도록 설계한다.
관심종목 리스트를 상단에 고정하여 반복 조회 편의성을 높인다.
- 좌측 거시패널, 우측 종목패널
- 관심종목 상단 고정
- 지표 클릭 시 상세 차트 팝업
## 5. 데이터 파이프라인 및 리스크
패널별 데이터 로딩 실패와 지연 데이터를 구분하여 표시하고, 서로 다른 기준일의 데이터가 혼재하는지 검증한다. 지표별 발표 주기와 허용 지연 시간을 기준으로 갱신 상태를 관리하며 공시·컨센서스 반영 지연 및 데이터 출처·라이선스 요건은 후속 확정한다.
데이터는 공공 API와 시세 벤더로부터 일 1회 배치 수집하며 장중 주요 지표는 별도 실시간 연동을 검토한다.
데이터 벤더 장애 시 직전 유효값을 유지하고 화면에 지연 표시를 노출하는 대체 로직을 마련한다.
- 일 1회 배치 수집 원칙
- 장중 실시간 연동 검토
- 벤더 장애시 직전값 유지+지연표시
