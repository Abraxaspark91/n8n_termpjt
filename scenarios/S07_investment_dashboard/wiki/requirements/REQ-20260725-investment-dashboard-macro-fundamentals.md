## 요건

투자 대시보드에 거시경제 현황 패널과 개별 종목 펀더멘털 분석 패널을 독립 영역으로 정의한다.

### 거시경제 현황 패널

- 금리, 물가, 환율, 주요 지수 등 시장 전반 지표를 배치할 수 있어야 한다.
- 대상 국가, 시장 범위, 지원 자산군은 후속 확정한다.

### 개별 종목 펀더멘털 분석 패널

- 기본 지표로 PER, PBR, 부채비율, 잉여현금흐름을 제공한다.
- 재무, 밸류에이션, 실적, 컨센서스 지표를 확장할 수 있는 구조를 반영한다.
- 지표 산식, 우선순위, 대상 자산군은 후속 확정한다.

### 지표 갱신 및 신선도 표시

- 갱신 유형을 실시간, 일중, 일간, 주간, 월간, 발표 시점으로 정의할 수 있어야 한다.
- 각 지표에 기준 시각, 최종 갱신 시각, 데이터 출처, 지연 여부를 표시한다.
- 지표별 목표 갱신 주기와 허용 지연 시간은 후속 확정한다.

### 테스트

- 패널별 데이터 로딩 실패를 검증한다.
- 지연 데이터가 사용자에게 적절히 표시되는지 검증한다.
- 서로 다른 기준일의 데이터가 혼재될 때 표시 및 경고 처리를 검증한다.
- 지표 사전, 데이터 신선도 UX, 확장 테스트 범위는 후속 정의한다.

## 결정

승인 페이로드에 포함된 변경사항을 반영한다. 투자 대시보드 기능정의서, 지표 갱신 정책서, 데이터 요구사항 정의서, 테스트 시나리오를 추가·갱신하고, 산출물_설계서.docx, 요구사항_추적표.xlsx, 보고_장표.pptx를 `deliverable_patch` 기반 문서엔진으로 수정한다. LLM Wiki와 GitHub 반영을 완료 대상으로 기록한다.

DA 검토의 보완 권고에 따라 지표 사전, 공통 데이터 모델, 데이터 출처 및 라이선스, 신선도 SLA, 지표 산식, 장애·정정 처리, 컴플라이언스 및 cross-module 영향 분석은 후속 확정 사항으로 남긴다.

## 리스크

- 지표별 발표 주기와 지연 시간이 달라 패널 간 기준 시각이 일관되지 않을 수 있다.
- 실시간 또는 고빈도 갱신 적용 시 데이터 제공 비용과 시스템 부하가 증가할 수 있다.
- 지표 정의와 데이터 출처가 확정되지 않으면 값과 갱신 시점이 달라질 수 있다.
- 공시·컨센서스 반영 지연으로 화면 표시값과 최신 투자 판단 사이에 차이가 발생할 수 있다.
- 패널 분리로 거시경제와 개별 종목 간 연관성이 과도하게 단순화될 수 있다.

## 후속 확정 질문

- 거시경제 지표의 대상 국가와 시장 범위는 무엇인가?
- 재무·밸류에이션·컨센서스 지표의 우선순위는 어떻게 정할 것인가?
- 각 지표의 목표 갱신 주기와 허용 데이터 지연 시간은 얼마인가?
- 데이터 제공업체, 출처 표기 기준, 라이선스 및 컴플라이언스 요건은 무엇인가?
- 지원할 대상 자산군과 시장 범위는 어디까지인가?
- 장 마감 후 공시·경제지표 발표 시 갱신 및 재처리 기준은 무엇인가?
- 공통 데이터 모델과 연관 모듈의 영향 범위는 어떻게 확정할 것인가?
- 지표 사전, 데이터 신선도 UX, 확장 테스트 범위는 어떻게 정의할 것인가?
