# SAP CO-PA 마케팅 퍼널 기반 판관비 구조화 손익계산서 설계서
본 문서는 마케팅 퍼널 단계(인지-관심-전환-유지) 기준으로 판관비를 구조화하여 CO-PA 손익계산서에 반영하기 위한 설계 내용을 정의한다.
## 1. 배경 및 목적
현행 CO-PA 손익계산서는 판관비를 부서 기준으로만 구분하여 마케팅 투자 대비 성과 분석이 어렵다.
본 과제는 판관비를 마케팅 퍼널 단계별로 재구조화하여 채널별 투자 효율성을 손익 관점에서 분석 가능하게 한다.
- 부서 기준 분류의 한계
- 퍼널 단계별 성과 분석 요구 증가
- 채널 ROI 측정 체계 필요
## 2. Marketing Funnel 개념
마케팅 퍼널은 인지(Awareness), 관심(Interest), 전환(Conversion), 유지(Retention)의 4단계로 정의한다.
각 단계는 대표 마케팅 활동과 비용 항목을 매핑하여 손익 분석의 최소 단위로 사용한다.
- 인지: 브랜드 광고, PR
- 관심: 콘텐츠 마케팅, SEO
- 전환: 퍼포먼스 광고, 프로모션
- 유지: CRM, 멤버십 운영비
### 2.1 퍼널단계별 비용유형
각 퍼널 단계는 매체비, 대행수수료, 인건비, 제작비의 4개 비용유형으로 세분화한다.
비용유형은 GL계정과 1:1 매핑되어 자동 분류가 가능하도록 설계한다.
- 매체비: 광고 매체 집행 비용
- 대행수수료: 에이전시 수수료
- 인건비: 마케팅 인력 배분비용
- 제작비: 콘텐츠/소재 제작비용
## 3. 계정 매핑 설계
기존 GL계정 체계를 유지하면서 CO-PA 특성값(Value Field)에 퍼널단계 코드를 추가한다.
전표 입력 시 원가요소와 특성값을 함께 지정하도록 하여 수기 배부 작업을 최소화한다.
- GL계정은 유지, 특성값만 추가
- 전표 입력 시 퍼널단계 필수 지정
- 월별 배부전표는 배치로 일괄 처리
### 3.1 원가요소-PA특성값 매핑
원가요소별 매핑 규칙은 마케팅팀과 재무팀이 공동으로 검토하여 확정한다.
예외적으로 복수 퍼널에 걸친 비용은 사전 정의된 비율로 안분한다.
- 원가요소-특성값 1:1 매핑 원칙
- 복수퍼널 비용은 사전 비율로 안분
- 매핑 규칙 분기별 재검토
## 4. 리포트 화면 설계
CO-PA 리포트는 퍼널단계 × 손익항목의 매트릭스 형태로 설계하여 단계별 기여이익을 즉시 확인할 수 있다.
채널별 드릴다운 기능을 제공하여 세부 캠페인 단위까지 손익을 추적할 수 있도록 한다.
- 퍼널단계 × 손익항목 매트릭스
- 채널/캠페인 드릴다운 지원
- 전월 대비 증감 시각화
## 5. 검증 및 이관 계획
신규 리포트는 기존 부서기준 리포트와 1개 분기 병행 운영하여 수치 정합성을 검증한다.
검증 완료 후 마케팅 예산 배정 프로세스에도 퍼널 기준 리포트를 반영한다.
- 1개 분기 병행 운영 및 검증
- 검증 완료 후 예산 프로세스 반영
- 사용자 교육 및 매뉴얼 배포
